# Student Management System

A CRUD-based Student Management System developed using Django, HTML, CSS, and SQLite.

## Features

- Add Student
- View Student
- Edit Student
- Delete Student
- Student details management

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub

## How to Run

1. Activate the virtual environment.
2. Run the Django development server:

```bash
python manage.py runserver
